# 🚀 Career Advisor Bot | Профориентационный Telegram-бот

Персонализированный помощник для СОВЕРШЕННОЛЕТНИХ, помогающий найти идеальный карьерный путь. Проект разработан в рамках итогового задания курса.

## 📋 О проекте
Бот помогает пользователям, столкнувшимся с трудностями выбора профессии. Система анализирует запросы, предлагает варианты развития и предоставляет информацию в удобном текстовом и интерактивном формате.


## ✨ Ключевые функции (Демо-версия)
- **Персонализация:** Адаптация рекомендаций под конкретный запрос пользователя (возраст, интересы, текущий опыт).
- **Интерактивность:** Удобное взаимодействие через систему кнопок (Reply/Inline) и текстовые команды.
- **База знаний:** Интеграция с базой данных (SQL) для хранения информации о профессиях и пользователях.
- **Масштабируемость:** Архитектура на принципах ООП, позволяющая легко дополнять функционал.

## 🛠 Технологический стек
- **Язык:** Python 3.10+
- **Библиотека бота:** aiogram 3.x (или telebot)
- **База данных:** SQLite / PostgreSQL
- **Архитектура:** ООП (Object-Oriented Programming)
- **Версионность:** Git

## 📂 Структура базы данных
Для работы бота необходимы следующие сущности:
1. `Users` — данные пользователя (id, возраст, интересы).
2. `Professions` — каталог профессий (название, описание, необходимые навыки).
3. `Recommendations` — логика связей между интересами и профессиями.

## 🗺 План разработки (Roadmap)

Проект разбит на 4 логических этапа для обеспечения стабильной демо-версии:

1.  **Этап 1: Инфраструктура (Sprint 1)**
    *   Настройка репозитория, окружения и `config.py`.
    *   Создание архитектуры БД (SQL) и базовых классов для работы с ней.
2.  **Этап 2: Проектирование диалогов (Sprint 2)**
    *   Создание главного меню и навигации (Reply/Inline кнопки).
    *   Реализация FSM (Машины состояний) для сбора данных о пользователе.
3.  **Этап 3: Логика рекомендаций (Sprint 3)**
    *   Разработка алгоритма мэтчинга интересов пользователя с базой профессий.
    *   Наполнение базы данных тестовыми специальностями.
4.  **Этап 4: Тестирование и деплой (Sprint 4)**
    *   Написание простых тестов (Unit-тесты для логики).
    *   Подготовка демо-версии к запуску.

## 🛠 Анализ ресурсов (Что "под капотом")

### ♻️ Можно использовать повторно (из прошлых проектов):
*   **Каркас бота:** Шаблон запуска `main.py` и инициализация `Dispatcher` (aiogram).
*   **Шаблоны кнопок:** Базовая логика создания `ReplyKeyboard` и `InlineKeyboard`.
*   **Database Connector:** Базовый класс для подключения к SQLite (методы `connect`, `close`, `execute`).

### 🆕 Нужно написать с нуля:
*   **FSM-сценарий (Опросник):** Логика сбора данных именно под профориентацию (возраст, хобби, навыки).
*   **Алгоритм подбора:** Код, который на основе ответов пользователя фильтрует записи в БД и выдает «Персонализированный ответ».
*   **Формат вывода:** Оформление описания профессий так, чтобы это было легко читать подросткам (использование эмодзи, структурированный текст).

### 🆘 Где может понадобиться помощь:
1.  **Проектирование БД:** Как правильно связать таблицу "Интересы" и "Профессии" (отношение многие-ко-многим), чтобы поиск был точным.
2.  **Сложная логика FSM:** Обработка случаев, когда пользователь нажал «назад» или ввел некорректный текст посреди опроса.
3.  **Тестирование:** Как правильно симулировать сообщения пользователей для автоматической проверки бота.



## 🚀 Запуск проекта

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте конфигурацию:**
   Создайте файл `.env` и добавьте туда ваш токен бота:
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ```

4. **Запустите бота:**
   ```bash
   python main.py
   ```
